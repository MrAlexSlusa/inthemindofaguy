# all-texts

Drop Word documents here, in the folder for the section they belong to:

    all-texts/opinions/      → /opinions/<slug>/
    all-texts/deep think/    → /deep-think/<slug>/
    all-texts/books/         → /books/

Nothing in this folder is published. It is the inbox: a text goes live only once
it has been added to `src/content.js` and pushed.

Useful to include at the top of the document, or just say it in chat:

- the date to show
- a one-line dek for the index page
- for books: author, year, pages, how you got it, and the mark out of five
