# drafts

Drop Word documents here (`.docx`) — one post per file.

Nothing in this folder is published. It is the inbox: a draft becomes a live
post only when its content is added to `src/content.js` and pushed.

Naming helps but is not required. If the filename says the section, it saves a
question — e.g. `opinion - hobbies should stay bad.docx`,
`deep think - on leaving cities.docx`, `book - a book about tides.docx`.

Useful to include at the top of the document, or just say it in chat:

- which section it belongs to (opinions / deep think / books)
- the date to show
- a one-line dek for the index page
- for books: author, year, pages, how you got it, and the mark out of five
