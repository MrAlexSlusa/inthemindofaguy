# Idea backlog

The daily task takes the **first unused idea from the Backlog** unless it has a
clearly better one — something tied to the day, to a thing the user mentioned
in a reply, or to the post that went up most recently. A better idea is allowed
and welcome; add it to the top of the Backlog first so there is a record.

After an idea is proposed, move its line to **Used** with the date and the
outcome. Never propose a subject already in Used, and never repeat a subject
the user has declined.

Each line is: **angle** — the specific claim, and the number or mechanism the
piece can lean on. The angle matters more than the title; titles get written
with the draft.
